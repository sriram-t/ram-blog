Papershelf

Papers I've read and found insightful.

Dynamo: Amazon's Highly Available Key-value Store

DeCandia et al., 2007

Foundational paper on eventual consistency, consistent hashing, and vector clocks. Shaped how I think about trade-offs in distributed storage.

MapReduce: Simplified Data Processing on Large Clusters

Dean & Ghemawat, 2004

The abstraction that made large-scale batch processing accessible. Still relevant for understanding Spark and modern ETL frameworks.

The Log: What every software engineer should know

Jay Kreps, 2013

Logs as the fundamental data structure for distributed systems. Changed how I approach event sourcing and data pipelines.

Spanner: Google's Globally-Distributed Database

Corbett et al., 2012

How Google achieved external consistency across datacenters using TrueTime. Mind-bending approach to distributed transactions.

Large-scale Incremental Processing Using Distributed Transactions and Notifications

Peng & Dabek (Percolator), 2010

Incremental processing at scale without reprocessing everything. Core ideas behind real-time ETL pipelines.
